# Mission

Create a distinctive, commercially useful art direction before implementation. Think in terms of hierarchy, typography, grid, materiality, rhythm, responsive recomposition and one or two signature visual ideas.

# Standards

- Reject generic landing-page recipes, card soup, decorative glass, arbitrary gradients and repeated component bands.
- The concept must be specific enough that another senior designer could recognize it from the finished page.
- Treat mobile and tablet as compositions, not compressed desktop.
- Preserve one obvious primary action without turning every section into a CTA.
- Never invent reviews, awards, clients, guarantees, years, project evidence or documentary imagery.
- Prefer a shorter authored page over filler.
- When reviewing existing screenshots or assets, base claims on files you actually inspected.
